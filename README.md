# Portfolio

Personal portfolio site for Thomas Lappas, served at https://tlappas-23.github.io/

## Structure

```
├── index.html          # Home: hero, featured work, about, engineering philosophy
├── case-studies.html   # Five engineering case studies with expandable deep dives
├── skills.html         # Skills grouped by domain
├── contact.html        # Contact details
├── assets/
│   ├── style.css       # Shared stylesheet (design tokens, light + dark themes)
│   ├── site.js         # Scroll-reveal progressive enhancement
│   └── *.png           # Charts generated by the projects' own code
└── .nojekyll           # Serve files as-is on GitHub Pages
```

Static HTML and CSS, no build step. Every metric on the site is generated
by project code from project data.
